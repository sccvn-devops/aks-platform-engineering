## Guardrails

- No secret value may appear in a log, an error, a document or a fixture.
- Every write goes through the single vault path; no caller builds its own client.
- A default write never revives a soft-deleted secret.
- Rotation runs only where the cluster holds the lease.
- A new catalogued secret names its mode and its consumers.
- Treat everything under `docs/IDPGitOps-Specs/` as read-only while implementing; a shape that does not fit is a spec bug to report.
- Status cells move through `docs_flow.py task`, one legal transition at a time, and a `done` cites a check that ran here.
- One task at a time, in the order the task file gives.
