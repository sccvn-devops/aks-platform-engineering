## Guardrails

- Nothing may make a cluster act as active without holding the lease.
- Never widen the configuration bounds to make a test pass; an unsafe pair is a startup refusal by design.
- Never make a controller highly available; a crashed one is self-healing within a lease term.
- Never scale up on an unreadable or unrecognised status.
- Never test against real Azure Storage or a real cluster; fakes at the narrow interfaces.
- Keep every binary entry point wiring-only.
- Treat everything under `docs/IDPGitOps-Specs/` as read-only while implementing; a shape that does not fit is a spec bug to report.
