## Guardrails

- Never add an SLO numeric, pause duration or traffic weight outside `tools/service_seed/profiles/`.
- Never hardcode a region, subscription, resource group or vault name; read the catalogue.
- Never let a credential reach a log, an error, a commit message, a branch name or a change-set description.
- Never merge, apply or provision — the pipeline proposes.
- Every outbound call takes an explicit timeout.
- Validate before creating anything external.
- Treat everything under `docs/IDPGitOps-Specs/` as read-only while implementing; a shape that does not fit is a spec bug to report.
- Status cells move through `docs_flow.py task`, one legal transition at a time, and a `done` cites a check that ran here.
- One task at a time, in the order the task file gives.
